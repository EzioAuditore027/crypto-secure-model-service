Cryptography-Based Secure Model Service

An end-to-end cryptographic client-server architecture serving a machine learning classifier with Post-Quantum Key Encapsulation (Lattice-KEM), HKDF key derivation, AEAD authenticated encryption, anti-replay guards, and continuous model updating.

1. Owner / Admin Application

Management

Manages model lifecycle, reviews registration requests, monitors user feedback data, and triggers continuous retraining.

  • BuildModel(D) → M: Initial model training & deployment
  • ApproveUser(UID): Authorize or revoke user access
  • ViewNewData() & DownloadNewData() → D'
  • RebuildModel(D, D') → M': Incremental model fine-tuning

Client Portal

Interacts with the server over an authenticated, end-to-end encrypted channel protected by Post-Quantum KEM and AEAD.

Cryptographic Protocol Pipeline

RFC 5869 & RFC 8439
1. Key Encapsulation
Lattice-KEM (Kyber-style LWE) or X25519 creates ephemeral shared secret K
2. Key Derivation
HKDF-SHA256 derives directional keys: K_client, K_server, IV salts
3. AEAD Encryption
ChaCha20-Poly1305 ensures confidentiality & tamper-proof authenticity
4. Anti-Replay Guard
Strict monotonic sequence counters & unique 96-bit nonces per message
